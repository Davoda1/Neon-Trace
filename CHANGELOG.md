# Changelog

## 1.1.0

- Redesigned the native interface with clearer controls, consistent typography and content-sized dialogs.
- Added Ctrl + scroll map zoom, Ctrl + drag panning, horizontal wrapping, bounded vertical movement and automatic route framing.
- Added a stopped-state Clear action that resets the interface while preserving preferences, saved history and installed databases.
- Refined multiple-target mode around simultaneous animated routes and optional measurement details.
- Made outward animations repeat with distance-weighted timing, synchronized hop bars and gentle active-hop following.
- Fixed journey-strip clipping for wrapped place names and kept manual scrolling in control.
- Added reliable normal window size, position and maximized-state restoration, including minimized-close handling.
- Improved Windows SDK resource-compiler discovery and removed unused-code warnings.

## 1.0.0

- Initial native Windows and Linux release with endpoint ping, route discovery, approximate map locations, multiple targets, offline demonstration, optional history and JSON/CSV/PNG exports.
