NeonTrace 1.1.0 improves the native interface, map navigation and animated journey presentation. It also adds reliable window placement restoration and a Clear action for returning a stopped session to the initial view.

### What's new

- Redesigned controls, consistent typography and content-sized About, Settings, History, Export and target dialogs.
- Ctrl + scroll zoom and Ctrl + drag panning, with horizontal map wrapping, vertical bounds and a Fit route action.
- A full-width multi-target map with simultaneous routes and optional measurement details.
- Repeating, distance-weighted eight-second journey animations with synchronized hop bars.
- Gentle active-hop following that respects manual scrolling, plus a dedicated scrollbar gutter for wrapped place names.
- Saved normal window size, position and maximized state, including closing while minimized.
- Improved Windows SDK resource-compiler discovery and unused-code cleanup.

### Downloads

Windows packages target Windows 11 x64. Linux packages target amd64 systems with an Ubuntu 24.04-equivalent or newer baseline.

- `NeonTrace-1.1.0-Windows-x64.zip` — portable Windows application.
- `NeonTrace-1.1.0-Linux-amd64.tar.gz` — portable Linux application.
- `NeonTrace-1.1.0-Linux-amd64.deb` — Debian/Ubuntu package.
- `NeonTrace-1.1.0-Source.zip` and `NeonTrace-1.1.0-Source.tar.gz` — complete source archives.
- `NeonTrace-1.1.0-Preview.html` — simplified offline browser demonstration with fictional data; no network probes.
- `NeonTrace-1.1.0-README-Notes.txt` — operating notes, privacy information and credits.
- `SHA256SUM.txt` — SHA-256 checksums for the other seven assets.

Extract portable archives completely before running the executable. The Windows EXE and Linux binary are at their archive roots. The Debian package installs a regular executable at `/usr/bin/neontrace`.

Map locations remain approximate, curves are schematic, and animation progress is independent of network measurements. Local history remains disabled by default.
